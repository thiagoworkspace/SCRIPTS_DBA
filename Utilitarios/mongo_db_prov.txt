A Chave _id
Todo  registro no banco vem com uma chave chamada de _id;
Esta chave tem como objetivo criar um identificador unico para todo registro;
Ele consegue ser unico pois é baseado no tempo em que é criado, mesmo que os dados sejam inseridos simultaneamente, ids serão distintos;
Essa funcionalidade é que ele possui um indice, agilizando a consulta por esta chave;.
É retornado de forma automatica sempre que usa um find.

Removendo collections
Podemos remover collections quando elas nao forem mais necessárias ou se erramos o nome por exemplo.
O comando é: db.<collection>.drop()

Removendo bancos de dados
O comando é: db.dropDatabase()
Após os comando, todos os dados e collections serão excluidos.

Importar bancos em JSON
Um formato muito encontrado de bancos de mongodb é .json
Vamos utilizar uma funcionalidade de tools para realizar a import.
O comando é: mongoimport <arquivo> -d <database> -c <collection>
Desta maneira criamos um banco de dados nomeado e sua collection
(os arquivos estão no curso da udemy)
(tem que baixar o mongodb database tools)

Exportar bancos em JSON
Outra função comum é exportar bancos de dados;
Para esta ação utilizamos: mongoexport -c <collection> -d <database> -o <output>

Exportar muitas collections
Quando o banco possui mais de uma collection a melhor opção de exportação é o mongodump
Utilizamos assim: mongodump -d <banco> -o <diretorio>
(Criar um banco com duas collections para testar o mongodump)

Importando dados do mongodump
Para importar os arquivos gerados do mongodump, utilizamos o mongorestore
O comando é o seguinte: mongorestore <diretorio>
Não precisamos informar uma flag para o diretorio, apenas o caminho relativo a ele.

Forma de remover todos os bancos
Podemos criar um loop no nosso terminal que vai remover todos os bancos não necessarios.
Ou seja, precisamos preservar: admin, config e local
Os outros podem ser removidos.
Vamos criar o snippet e rodar no mongoshell.

Mongo().getDBNames().forEach(function(db)){
  if (['admin', 'config', 'local'].indexOf(db) <0){
      Mongo().getDb(db).dropDatabase();
     }
};

O que é CRUD?
CRUD é uma sigla para Create, Read, Upadte e Delete;
É onde inserimos dados, resgatamos/lemos dados, atualizamos dados e deletamos/removemos dados;
As quatro operações basicas de banco de dados, tanto relacional quanto não-relacional.
Praticamente toda aplicação terá um CRUD

Tudo é documento
Sempre que vamos trabalhar com MongoDB é comum adicionarmos varias entidades com chaves {}
Sempre que adicionamos chave a algum local, chamamos de document (documento)
Ou seja, é bem comum ouvir: inserir um document na collection
Onde em SQL seria, inserir o dado na tabela.

Inserindo dados
Para inserir um document utilizamos o método insertOne
desta maneira: db.<collection>.insertOne({<dados>})
Onde dados representa o conjunto de chaves e valores do dado em questão

Nao ha relação entre os dados
Em uma collection nao precisamos respeitar as chaves dos outros documents.
Ou seja, o banco relacional precisa adicionar dados das colunas e em mongodb nao existe essa regra
Então podemos ter documents totalmente diferentes em uma collection

VOLTANDO AO _ID
Já sabemos que o _id é unico e é criado em todos os documents da collections
Porem nao necessariamente precisamos deixar o mongodb criar
podemos criar nosso proprio _id
exemplo: db.<collection>.insertOne({_id: "meuId", nome: "Matheus"})
db.mercado.insertOne({_id: "1001", nome: "Vassoura", preco: 14.99})
